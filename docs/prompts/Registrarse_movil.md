# Prompt 3 · Pantalla “Registrarse” (móvil)

Actúa como un diseñador de producto senior. Diseña la pantalla “Registrarse ” para una aplicación móvil diseñada para facilitar la gestión de comunidades de propietarios en edificios y urbanizaciones, centralizando el control de gastos, los pagos y la comunicación entre vecinos.
Elementos en pantalla:

* Nombre de la app en la parte “superior izquierda”
* Titulo Grande ¡Bienvenido nuevo vecino!
* Breve descripción Gracias por unirte a nuestra comunidad
* Campo Usuario
* Campo Piso
* Campo Puerta (estos dos campos en la misma row)
* Campo Contraseña
* Button : registrarse

Comportamiento : El button de registrarse no estará activo hasta que los campos estén completos y estén bien escritos. Los textfield cuando te vas al otro campo - textfield dará error si esta mal escrito
Estilo visual: Limpio,minimalista y  moderno pero visualmente claro con opción a modo oscuro, colores (#0E7C86, #12304A, #FF6B57,#F5B83D,#2E9E6B,#F6F3EC) tipografía limpia tipo Inter.
Entrégame el resultado en formato png (ya que es un ejemplo y no el real)
