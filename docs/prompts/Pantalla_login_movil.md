# Prompt 1 · Pantalla “Login / para acceder” (móvil)

Actúa como un diseñador de producto senior. Diseña la pantalla “login / para acceder ” para una aplicación móvil diseñada para facilitar la gestión de comunidades de propietarios en edificios y urbanizaciones, centralizando el control de gastos, los pagos y la comunicación entre vecinos.
Elementos en pantalla:

* Logo y título de bienvenida (el logo que has creado primero)
* Button 1 : Acceder (Algo así), donde al clicar se redirigirá a una nueva pantalla indicando que introduzca el usuario y contraseña.
* Button 2 : Soy nuevo! Registrate , donde al clicar se le abrira una nueva pantalla con un mensaje de bienvenida, tipo encantado nuevo vecino etc y se le pedirá : nombre, piso, contraseña

Estilo visual: Limpio,minimalista y  moderno pero visualmente claro con opción a modo oscuro, colores (#0E7C86, #12304A, #FF6B57,#F5B83D,#2E9E6B,#F6F3EC) tipografía limpia tipo Inter.
Entrégame el resultado en formato png (ya que es un ejemplo y no el real)
