## 🔖 Cómo leer esta bitácora

Cada sesión de trabajo tiene su propia ficha con este formato:

- **Qué hice:** tareas realizadas en la sesión.
- **Cuánto:** tiempo dedicado.
- **Qué falló:** problemas que me encontré.
- **Cómo lo resolví:** soluciones aplicadas.
- **Qué me llevo:** reflexión y aprendizaje.

Al final del mes hay un cuadro resumen con horas, logros, puntos a mejorar y siguientes objetivos.

**Etiquetas de sesión**

| Etiqueta | Significado |
|:--:|---|
| 🧭 | Planificación y organización |
| 🛠️ | Desarrollo / trabajo práctico |
| 📖 | Aprendizaje e investigación |
| 🤝 | Reunión o trabajo con el equipo |
| 🧪 | Pruebas y depuración |
| 🚧 | Sesión con bloqueos |
| 🚀 | Sesión muy productiva |
